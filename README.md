NeoTech Consulting - Proyecto Final 

Este proyecto consiste en el desarrollo de la plataforma corporativa para NeoTech Consulting, una consultora tecnológica ficticia especializada en soluciones digitales avanzadas. El sitio integra tecnologías modernas de frontend para ofrecer una experiencia de usuario fluida, dinámica y visualmente atractiva. 

🚀 Características Principales 

Renderizado Dinámico: Los catálogos de servicios y los perfiles del equipo se generan automáticamente mediante JavaScript a partir de estructuras de datos. 

Interactividad Avanzada: Uso de bibliotecas de animación para mejorar el feedback visual (AOS, Anime.js). 

Integración 3D: Incorporación de modelos interactivos mediante Spline. 

Diseño Responsive: Interfaz totalmente adaptada a dispositivos móviles, tablets y escritorio utilizando Tailwind CSS. 

Formulario de Contacto: Sistema de validación en tiempo real para la captación de leads. 

🛠️ Tecnologías Utilizadas 

HTML5 Semántico: Para una estructura clara y accesible. 

Tailwind CSS: Framework de utilidades para un diseño moderno y escalable. 

JavaScript (ES6+): Lógica de manipulación del DOM y carga dinámica de contenido. 

Librerías Externas: 

AOS: Animaciones al hacer scroll. 

Anime.js: Micro-interacciones y animaciones complejas. 

Swiper.js: Carrusel táctil para la sección de empleo. 

Spline: Visualización de elementos 3D. 

📁 Estructura del Proyecto 

index.html: Página principal con secciones de Inicio, Servicios, Equipo y Contacto. 

trabajo.html: Sección dedicada a la captación de talento y cultura empresarial. 

style.css: Estilos personalizados, gradientes y efectos de glassmorphism. 

function.js: Lógica de renderizado, validación de formularios y animaciones.
